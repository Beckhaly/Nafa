Ouvrez l'application dans votre navigateur 2. Entrez vos identifiants: - **Email**: Votre adresse email - **Mot de passe**: Votre mot de passe fourni 3. Cliquez **"Se connecter"** > ⚠️ **Important**: Changez votre mot de passe lors de la première connexion! --- ## 🔐 Connexion ### Écran de connexion | Champ | Description | |-------|-------------| | **Email** | Votre adresse email enregistrée | | **Mot de passe** | Votre mot de passe | ### Actions disponibles - **Se connecter**: Accéder à votre compte - **Mot de passe oublié?**: Réinitialiser votre mot de passe ### Après connexion - ✅ Vous êtes redirigé vers le **Tableau de bord** - 🔒 Votre session reste active pendant 2 heures - 🚪 Cliquez votre nom en haut à droite pour vous **déconnecter** --- ## 📊 Tableau de bord Le tableau de bord affiche un résumé de l'association en temps réel. ### 🔢 Indicateurs clés (KPIs) | Indicateur | Description | |-----------|-------------| | **💰 Solde caisse** | Solde financier actuel de l'association | | **👥 Membres actifs** | Nombre de membres actuellement actifs / Total | | **📊 Taux recouvrement** | % des cotisations mensuelles payées ce mois | | **📈 Créances en souffrance** | Montant total impayé (cotisations + CEX) | | **💵 Dépenses par catégorie** | Répartition des dépenses par type | ### 📈 Graphiques - **Recettes vs Dépenses**: Comparaison mensuelle des entrées/sorties - **Répartition dépenses**: Visualisation par catégorie ### 🎯 Actions rapides - ➕ Ajouter un membre - 📝 Enregistrer une cotisation - 🎉 Créer un événement - 📢 Publier une annonce --- ## 👥 Gestion des membres ### Accès Menu latéral → **Membres** ### 📋 Liste des membres #### Affichage - **Tableau** avec colonnes: Nom, Rôle, Téléphone, Statut - **Recherche**: Cherchez par nom, email ou téléphone - **Filtres**: Par statut (Actif, Inactif, Suspendu) #### Actions sur un membre | Action | Description | |--------|-------------| | **Clic sur la ligne** | Affiche le détail du membre | | **Modifier** | Éditer les informations | | **Voir la fiche** | Télécharger la carte de membre | | **Supprimer** | Supprimer le profil (si aucune dette) | ### ➕ Ajouter un membre 1. Cliquez **"+ Ajouter membre"** 2. Remplissez le formulaire: | Champ | Type | Obligatoire | |-------|------|-----------| | **Nom** | Texte | ✅ | | **Prénom** | Texte | ✅ | | **Alias** (surnom) | Texte | ❌ | | **Téléphone** | Téléphone | ✅ | | **Email** | Email | ❌ | | **Date d'adhésion** | Date | ✅ | | **Rôle** | Sélecteur | ✅ (Défaut: Membre) | | **Lieu d'habitation** | Texte | ❌ | | **Emploi** | Texte | ❌ | | **Commentaires** | Texte libre | ❌ | 3. Cliquez **"Enregistrer"** **Résultat**: Un **matricule** est généré automatiquement (format: `MBR-2026-001`) ### ✏️ Modifier un membre 1. Cliquez sur le membre 2. Cliquez **"Modifier"** 3. Changez les informations 4. Cliquez **"Enregistrer"** ### 👤 Détail du membre Affiche: - Informations personnelles - Rôle et statut - Historique des cotisations - Prêts actifs (s'il y a) - Événements auxquels il participe - Carte de membre (à télécharger) --- ## 💰 Gestion des cotisations ### Accès Menu latéral → **Cotisations** ### 📅 Onglet "Mensuelles" La **matrice de cotisations** affiche tous les membres et leurs paiements par mois/année. #### Codes couleur | Couleur | Signification | |---------|---------------| | 🟢 **Vert** | Payé (100%) | | 🟡 **Jaune** | Partiel (< 100%) | | 🔴 **Rouge** | Impayé (0%) | | ⚪ **Gris** | Mois futur | #### Actions sur une cellule - **Cliquez la cellule**: Ouvre le formulaire de paiement - **Saisissez le montant**: Montant versé - **Sélectionnez la date**: Date du paiement - **Cliquez "Enregistrer"**: Crée un reçu automatiquement #### 📊 Statistiques mensuelles Affichées en haut: - **Membres actifs**: Nombre dans la matrice - **Taux recouvrement**: % du total payé - **Total théorique**: Somme attendue - **Total payé**: Somme reçue - **Reste dû**: Différence ### 🎟️ Onglet "Exceptionnelles" Gestion des cotisations ponctuelles (fêtes, urgences, etc). #### Créer un appel de fonds 1. Cliquez **"+ Nouvel appel"** 2. Remplissez: | Champ | Description | |-------|-------------| | **Libellé** | Nom de l'appel (ex: "Fête de Noël") | | **Source** | Événement ou Annonce liée (optionnel) | | **Sélectionnez la source** | Choisissez l'événement/annonce | | **Montant par membre** | Cotisation individuelle | | **Date limite** | Échéance de paiement | 3. Cliquez **"Créer"** **Résultat**: L'appel est créé pour **tous les membres actifs** #### Enregistrer un paiement CEX 1. Dans l'appel, cliquez sur le membre 2. Entrez le montant payé 3. Cliquez **"Enregistrer paiement"** #### 📊 Statistiques CEX - **Appels lancés**: Total des appels - **Taux recouvrement**: % du montant dû payé - **Total dû**: Somme totale demandée - **Total payé**: Somme reçue - **Reste dû**: Différence (en rouge) --- ## 💳 Gestion des prêts ### Accès Menu latéral → **Prêts** ### 📋 Liste des prêts #### Affichage - **Cartes** avec: Membre, Montant, Durée, Statut - **Barre de progression**: Pourcentage remboursé - **Statuts**: Actif 💳 | En retard ⏰ | Soldé ✅ #### Actions | Action | Description | |--------|-------------| | **Cliquez la carte** | Affiche le tableau d'amortissement | | **Enregistrer paiement** | Enregistre une mensualité | | **Clôturer** | Marque le prêt comme soldé | ### ➕ Créer un prêt 1. Un email de réinitialisation sera envoyé. **Q: Un membre peut-il voir les données des autres?** R: Non. Les membres voir seulement leurs propres données. Les administrateurs voient tout. **Q: Comment supprimer un événement?** R: Vous ne pouvez pas le supprimer, mais vous pouvez le **marquer comme "Annulé"**. **Q: Où trouver les reçus de cotisation?** R: Les reçus sont générés automatiquement et affichés lors du paiement (format: `REC-2026-01-00001`). **Q: Peut-on modifier une cotisation enregistrée?** R: Non. Pour corriger, créez une nouvelle entrée avec le montant correct. **Q: Comment ajouter un utilisateur administrateur?** R: Allez dans **Paramètres** → **Utilisateurs** (si vous êtes admin). Seul l'admin peut faire cela. **Q: WhatsApp ne fonctionne pas, pourquoi?** R: Vérifiez dans **Paramètres** → **Diffusion** que "Activer WhatsApp" est ☑️. Sinon, contactez l'admin. ### 🔧 Dépannage **Problème**: "Erreur à la sauvegarde" - Solution: Vérifiez votre connexion Internet et réessayez **Problème**: "Le membre n'apparaît pas après création" - Solution: Rafraîchissez la page (Ctrl+R ou Cmd+R) **Problème**: "Je ne peux pas enregistrer un paiement" - Solution: Vérifiez que la cotisation existe pour ce mois **Problème**: "Le SMS n'a pas été envoyé" - Solution: Vérifiez le numéro de téléphone du membre (format correct?) **Problème**: "L'application est lente" - Solution: Videz le cache de votre navigateur (Ctrl+Shift+Delete) ### 📧 Contacter le support Si vous avez un problème non résolu: 1. **Notez les détails**: - Que faisiez-vous? - Quel message d'erreur? - Quand c'est arrivé? 2. **Contactez**: - Email: L'adresse email de support fournie par votre administrateur - Téléphone: Numéro de contact fourni par votre administrateur --- ## 🎓 Bonnes pratiques ### ✅ À FAIRE ✓ Enregistrer les cotisations **chaque mois** ✓ Archiver les **anciennes annonces** ✓ Faire des **backups réguliers** ✓ Tenir à jour les **numéros de téléphone** ✓ Documenter les **décisions en notes** ✓ Vérifier les **discordances** mensuelles ### ❌ À ÉVITER ✗ Partager votre **mot de passe** ✗ Publier des **annonces fausses** ✗ Modifier des **paiements vérifiés** ✗ Laisser des données **incomplètes** ✗ Oublier les **sauvegardes** --- ## 📚 Ressources supplémentaires - **Documentation complète**: Consultez la documentation en ligne - **Vidéo tutorielle**: Liens vers les vidéos d'aide - **Webinaire**: Formations en direct (dates à vérifier) - **Community**: Forum d'entraide --- ## 📞 Informations de contact Contactez votre administrateur pour obtenir les coordonnées de support appropriées selon votre besoin: - Support technique - Facturation - Compte utilisateur --- **Version du guide**: 1.0 **Dernière mise à jour**: 2026-07-01 **Application**: Nafa v1.0 📖 **Pour plus d'aide, consultez le menu "?" en haut de l'application.**
