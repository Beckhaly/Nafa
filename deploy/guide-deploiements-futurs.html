2. Premier déploiement (installation complète)

Exécuter ces commandes dans un terminal SSH sur le VPS (ssh root@102.204.205.121).

Étape 1 — Installer le stack serveur

Durée estimée : 10–15 minutes. Ne pas interrompre.
# Mettre à jour le système
apt-get update && apt-get upgrade -y

# Installer les outils essentiels
apt-get install -y curl wget git unzip zip build-essential \
  software-properties-common apt-transport-https ca-certificates

# PHP 8.2 (PPA Ondřej Surý — Ubuntu 24.04)
add-apt-repository -y ppa:ondrej/php && apt-get update
apt-get install -y php8.2 php8.2-cli php8.2-fpm php8.2-mysql \
  php8.2-gd php8.2-curl php8.2-zip php8.2-xml php8.2-mbstring \
  php8.2-intl php8.2-redis php8.2-bcmath
systemctl restart php8.2-fpm

# Composer
php -r "copy('https://getcomposer.org/installer', 'cs.php');"
php cs.php --install-dir=/usr/local/bin --filename=composer && rm cs.php

# MySQL 8
apt-get install -y mysql-server
systemctl enable --now mysql

# Node.js 18
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt-get install -y nodejs

# Nginx + Redis + Certbot
apt-get install -y nginx redis-server certbot python3-certbot-nginx
rm -f /etc/nginx/sites-enabled/default
systemctl enable --now nginx redis-server

Étape 3 — Cloner le code depuis GitHub

git clone https://github.com/Beckhaly/Nafa.git /var/www/nafa

Étape 4 — Déployer le backend Laravel

cd /var/www/nafa/backend-laravel

# Copier et configurer le .env
cp /var/www/nafa/deploy/.env.production .env
sed -i 's/CHANGE_ME_STRONG_PASSWORD/Nafa@Prod2026!/' .env

# Dépendances + migrations
composer install --optimize-autoloader --no-dev
php artisan key:generate
php artisan migrate --force
php artisan config:cache && php artisan route:cache && php artisan view:cache

# Permissions
chown -R www-data:www-data /var/www/nafa/backend-laravel
chmod -R 775 /var/www/nafa/backend-laravel/storage
chmod -R 775 /var/www/nafa/backend-laravel/bootstrap/cache

Étape 5 — Builder le frontend React

cd /var/www/nafa/frontend
npm ci
npm run build
chown -R www-data:www-data dist/

Étape 6 — Configurer Nginx (port 8081)

# Créer /etc/nginx/sites-available/nafa
upstream nafa_php {
    server unix:/run/php/php8.2-fpm.sock;
}
server {
    listen 8081;
    server_name mogoya26.nafa.nantalabs.com;
    root /var/www/nafa/frontend/dist;
    index index.html;
    client_max_body_size 100M;

    location / { try_files $uri $uri/ /index.html; }

    location /api {
        alias /var/www/nafa/backend-laravel/public;
        try_files $uri /api/index.php?$query_string;
        location ~ \.php$ {
            fastcgi_pass nafa_php;
            fastcgi_param SCRIPT_FILENAME $request_filename;
            include fastcgi_params;
        }
    }
    location /storage {
        alias /var/www/nafa/backend-laravel/storage/app/public;
    }
}

ln -sf /etc/nginx/sites-available/nafa /etc/nginx/sites-enabled/nafa
nginx -t && systemctl reload nginx

# Autoriser le trafic Docker → port 8081
ufw allow from 172.16.0.0/12 to any port 8081 proto tcp
ufw reload

Étape 7 — Configurer Caddy pour les deux domaines

# Créer /root/Caddyfile
happiness-shop.storebox.nantalabs.com {
    reverse_proxy storebox:3001
}

mogoya26.nafa.nantalabs.com {
    reverse_proxy host.docker.internal:8081
}

# Mettre à jour /root/deploy/docker-compose.yml :
# - Changer command: caddy reverse-proxy... → caddy run --config /etc/caddy/Caddyfile
# - Ajouter volume: /root/Caddyfile:/etc/caddy/Caddyfile:ro
# - Ajouter extra_hosts: host.docker.internal:host-gateway
# - Ajouter networks: [net, storebox-net] + déclarer storebox-net external

# Recréer le conteneur Caddy
docker stop storebox-caddy && docker rm storebox-caddy
cd /root/deploy
DOMAIN=happiness-shop.storebox.nantalabs.com \
  docker compose --env-file /root/storebox.env up -d --no-deps caddy
docker network connect storebox-net storebox-caddy
SSL Let's Encrypt est obtenu automatiquement par Caddy au démarrage. Aucune action manuelle requise.

3. Mises à jour du code (déploiements suivants)

Pour déployer une nouvelle version après un push sur GitHub :

# 1. Mettre à jour le code
cd /var/www/nafa && git pull origin main

# 2. Backend (si changements PHP/migrations)
cd /var/www/nafa/backend-laravel
composer install --optimize-autoloader --no-dev
php artisan migrate --force
php artisan config:clear && php artisan config:cache
php artisan route:cache && php artisan view:cache
chown -R www-data:www-data storage/ bootstrap/cache/

# 3. Frontend (si changements React)
cd /var/www/nafa/frontend
npm ci
npm run build
chown -R www-data:www-data dist/

# Nginx recharge automatiquement les nouveaux fichiers statiques
# Pas besoin de recharger Nginx pour les changements de fichiers
Pas besoin de redémarrer Caddy ni Nginx lors d'une simple mise à jour du code.

6. Commandes utiles de maintenance

Vérifier l'état des services

systemctl status nginx php8.2-fpm mysql redis-server
docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'

Consulter les logs

# Logs Laravel (erreurs PHP)
tail -f /var/www/nafa/backend-laravel/storage/logs/laravel.log

# Logs Nginx Nafa
tail -f /var/log/nginx/error.log

# Logs Caddy (SSL, accès)
docker logs -f storebox-caddy

Redémarrer les services

systemctl restart nginx
systemctl restart php8.2-fpm
systemctl restart mysql
docker restart storebox-caddy

Vider les caches Laravel

cd /var/www/nafa/backend-laravel
php artisan cache:clear
php artisan config:clear && php artisan config:cache
php artisan route:clear && php artisan route:cache
php artisan view:clear && php artisan view:cache

Sauvegarde base de données

mysqldump -u nafa_user -pNafa@Prod2026! nafa > /root/nafa-backup-$(date +%Y%m%d).sql

7. Dépannage (Troubleshooting)

SymptômeCause probableSolution
502 Bad Gateway sur Nafa Nginx ou PHP-FPM arrêté systemctl restart nginx php8.2-fpm
502 sur StoreBox Caddy pas connecté à storebox-net docker network connect storebox-net storebox-caddy
i/o timeout port 8081 UFW bloque le réseau Docker ufw allow from 172.16.0.0/12 to any port 8081 proto tcp
Erreur 500 Laravel Permissions storage ou .env chmod -R 775 storage/ bootstrap/cache/
SSL expiré Renouvellement Caddy raté docker restart storebox-caddy — Caddy renouvelle auto
DOMAIN manquant au compose Variable non passée Préfixer : DOMAIN=... docker compose ...
