Étapes effectuées

Correction des scripts de déploiement
Correction bug syntaxe bash (deploy.sh ligne 11) et URL GitHub hardcodée. Commit + push sur Beckhaly/Nafa (main).
Installation du stack serveur
PHP 8.2, Composer, MySQL 8, Node.js 18, Nginx, Redis, Certbot installés via apt. PHP-FPM configuré (upload 100MB, timeout 300s).
Création de la base de données MySQL
Utilisateur nafa_user créé, base nafa en utf8mb4, privilèges complets accordés.
Clonage du code source
git clone https://github.com/Beckhaly/Nafa.git vers /var/www/nafa (branche main, 12 089 fichiers).
Déploiement du backend Laravel
composer install, génération APP_KEY, php artisan migrate, config:cache, route:cache, view:cache. Permissions www-data configurées.
Build du frontend React
npm ci + npm run build (21.32s). Fichiers statiques dans /var/www/nafa/frontend/dist.
Configuration Nginx sur le port 8081
Nginx configuré sur port 8081 (non-conflictuel avec Caddy). Serve SPA React + proxyfie /api vers PHP-FPM via socket Unix.
Configuration Caddy multi-domaines
Remplacement de la commande CLI caddy reverse-proxy par un Caddyfile gérant les deux domaines. SSL Let's Encrypt obtenu automatiquement pour les deux.
Correction réseau Docker
Connexion de Caddy au réseau storebox-net (en plus de deploy_net) pour qu'il puisse joindre le conteneur storebox:3001. Règle UFW ajoutée pour 172.16.0.0/12 → port 8081.
